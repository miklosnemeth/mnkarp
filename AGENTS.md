# Instructions for AI agents working on mnKarp

mnKarp is the rack of mnKord and mnArpee (`../mnKord`, `../mnArpee`), whose sources it compiles in place. The rules of
mnKord's `AGENTS.md` apply here too: C++23, Semantic Versioning in **one** place (`project(mnKarp VERSION x.y.z)` in
`CMakeLists.txt`), and every change adds a line to `CHANGELOG.md` under `## [Unreleased] - x.y.z` (the same number),
written for the plugin's user. A MAJOR bump needs the owner's say-so.

## Build and test

```bash
cmake -S . -B build -DMNKARP_BUILD_TESTS=ON
cmake --build build --config Release
build/Release/mnKarpTests.exe        # must end with 0 failures
```

## Rules

- Do not copy code from mnKord or mnArpee into this folder, and do not edit them from here for the rack's sake alone:
  a change to one of them is made in its own repository (with its own version and changelog).
- The rack only talks to the two processors through their public interface and `createEditorIfNeeded()`. Both define a
  global `createPluginFilter()`, which CMake renames per source file; do not add a third definition.
- `PluginProcessor.h` exists in both plugins: include them as `<mnKord/PluginProcessor.h>` and `<mnArpee/PluginProcessor.h>`
  (forwarding headers generated by CMake).
- The editors of the two plugins must never be included in one translation unit (both have a `MnAudioUi.h` and global names);
  the rack creates them through the processors' `createEditor()`.

## Documentation and installer

- The user guide is `docs/USER_GUIDE.md` (English) and `docs/USER_GUIDE.hu.md` (Hungarian); update **both** when a control or
  behaviour changes. The screenshot `docs/images/main.png` is made by `build/Release/mnKarpTests.exe --screenshot docs/images/main.png`.
- The PDFs (`docs/mnKarp-User-Guide.pdf`, `docs/mnKarp-Felhasznaloi-utmutato.pdf`) go into the installer: run `python docs/build-pdf.py`
  after changing a guide (it uses mnKord's converter and needs Edge or Chrome) and commit them.
- The web pages `docs/index.html`, `docs/hu/index.html` and `docs/sitemap.xml` are generated: edit `site/build-site.py` and run
  `python site/build-site.py` (it reads the version from `CMakeLists.txt` and the stylesheet from mnKord's `site/site.css`).
- The installer (`installer/mnKarp.iss`) is built by the normal Release build when Inno Setup 6 is installed; it includes mnKord's
  `installer/MnAudioInstaller.iss`.
